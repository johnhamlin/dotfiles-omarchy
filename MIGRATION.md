# New Machine Setup Checklist

## Prerequisites
- [ ] CachyOS + Omarchy installed
- [ ] SSH keys available (copy `~/.ssh/` from backup or re-export from 1Password)

## Core Setup

1. **Install chezmoi**
   ```bash
   pacman -S chezmoi
   ```

2. **Initialize dotfiles**
   ```bash
   chezmoi init johnhamlin/dotfiles-omarchy
   ```

3. **Configure machine identity** — edit `~/.config/chezmoi/chezmoi.toml`:
   ```toml
   [data]
       machine = "desktop-name"
       formFactor = "desktop"

   [edit]
       command = "nvim"
   ```

4. **Apply dotfiles**
   ```bash
   chezmoi apply
   ```

5. **Authenticate GitHub CLI**
   ```bash
   gh auth login
   ```

6. **Install packages**
   ```bash
   # Explicit packages (from chezmoi repo)
   pacman -S - < ~/.local/share/chezmoi/packages-explicit.txt

   # AUR packages (review list first, install with your AUR helper)
   cat ~/.local/share/chezmoi/packages-aur.txt
   # paru -S $(cat ~/.local/share/chezmoi/packages-aur.txt | tr '\n' ' ')
   ```

7. **Install runtimes**
   ```bash
   mise install
   ```

## Post-Apply Configuration

8. **Configure monitors**
   ```bash
   hyprctl monitors  # identify connected monitors
   # Edit ~/.config/hypr/monitors.conf with correct desc/resolution/position
   # Then update chezmoi source for the new machine:
   # chezmoi add ~/.config/hypr/monitors.conf
   # Edit the .tmpl to add a new machine block
   ```

9. **Set theme**
   ```bash
   omarchy-theme-set "Tokyo Night"
   ```

10. **Copy Claude Code config**
    ```bash
    # From backup or old machine:
    cp -r /path/to/backup/.claude ~/
    ```

11. **Configure 1Password + SSH agent**
    - Install 1Password desktop app
    - Enable SSH agent in 1Password settings
    - Verify: `ssh-add -l`

12. **Import GPG keys** (if needed)
    ```bash
    gpg --import /path/to/backup/private-key.asc
    ```

## Items NOT Managed by chezmoi

| Item | Action |
|------|--------|
| `~/.ssh/` | Copy from encrypted backup or re-export from 1Password |
| `~/.gnupg/` | Copy keyring or re-import |
| `~/.config/gh/` | Run `gh auth login` |
| `~/.claude/` | Copy directory from old machine |
| `~/.config/omarchy/power-profiles/` | Auto-generated by `omarchy-power-mode` |

## Verification

```bash
chezmoi diff                                    # should show no diff after apply
chezmoi managed | wc -l                         # verify managed file count
chezmoi execute-template '{{ .formFactor }}'    # should print "desktop"
```
